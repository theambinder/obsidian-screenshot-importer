# Bundled UI Icons

These static assets are included locally; the app makes no runtime requests to icon providers.

- `obsidian.svg`: unmodified official gradient mark from https://obsidian.md/images/obsidian-logo-gradient.svg, linked by https://obsidian.md/brand, downloaded on 2026-10-03.
