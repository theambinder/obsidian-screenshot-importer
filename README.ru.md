# Obsidian Screenshot Importer

Локальное приложение для пакетного переноса скриншотов и изображений в заметки Obsidian. Источником может быть любой плеер, игра или папка с картинками.

[English README](README.md) · [GitHub](https://github.com/theambinder/obsidian-screenshot-importer)

## Переносимое приложение (рекомендуется)

Готовая автономная сборка для Apple Silicon и macOS 13.5+:

- `dist/Obsidian Screenshot Importer.app`
- `dist/Obsidian-Screenshot-Importer-1.4.1-Apple-Silicon.zip` для переноса на другой Mac. Готовая сборка доступна в [Releases](https://github.com/theambinder/obsidian-screenshot-importer/releases).

Распакуй ZIP, перенеси приложение в Applications и открой двойным кликом. Node.js, Homebrew и конвертеры устанавливать не нужно. Закрытие главного окна или Cmd+Q останавливает сервис; выполняющаяся обработка сначала завершается.

Папки выбираются в **Settings > Choose Folders...**. Имеющаяся папка `data` проекта подхватывается автоматически. Для общей истории на двух Mac выбери одну и ту же синхронизированную папку `data`; используй приложение только на одном Mac одновременно. Сам ZIP не содержит твои скриншоты и историю.

Подробности переноса, подписи macOS, данных, ограничений и пересборки: [PORTABLE-APP.md](PORTABLE-APP.md).

Версия отображается в Settings и About. Изменения релизов: [CHANGELOG.md](CHANGELOG.md). Параллельная конвертация регулируется в **Settings > Parallel Images**; по умолчанию Auto, качество и Effort не меняются. Результаты измерений: [PERFORMANCE.md](PERFORMANCE.md).

В Screenshots двойной клик по пустой галочке **Use** отмечает все папки с той же выбранной Note, а по уже активной галочке снимает выделение со всей группы. Другие Note не затрагиваются. Заголовки **Source**, **Note**, **S**, **E** переключают сортировку вверх / вниз / исходный порядок; кнопка **Reset sort** сразу возвращает порядок сканирования (новые по дате изменения сверху). На узком экране доступен список сортировки. Shift-выделение работает в текущем видимом порядке.

**Settings > Appearance > Theme**: System (по умолчанию, следует теме macOS), Light, Dark. Выбор сохраняется вместе с остальными настройками в `data/settings.json`.

Разделы **Screenshots**, **History** и **Settings** запоминают собственное положение прокрутки до закрытия приложения. Один клик по вкладке возвращает к последнему месту, двойной клик открывает верх раздела. При первом открытии раздел начинается сверху; позиции не записываются в настройки и не синхронизируются между Mac.

Номер эпизода **E** допускает `0` (например, S3E0), но не пустое значение. Если у выбранных папок совпали Note, сезон и эпизод, перед Run появляется окно **Duplicate episodes** со списком папок: **Cancel** отменяет запуск, **Continue Run** добавляет скриншоты под один заголовок эпизода. Архив и точечный rollback сохраняются отдельно для каждой исходной папки.

Начиная с 1.2.4 импорт и rollback сохраняют текущую **Created Date** файла заметки в macOS. **Modified Date** обновляется при изменении текста. Если дату создания сохранить не удается, файл заметки не заменяется. Даты, потерянные в старых версиях, автоматически не восстанавливаются.

Полная публичная история версий находится в [CHANGELOG.md](CHANGELOG.md). Локальная копия в Obsidian поддерживается согласно `AGENTS.local.md`, если этот файл есть в рабочей папке; личная заметка и локальные инструкции не публикуются.

## Старый запуск из исходников

Первичная настройка зависимостей на Mac разработчика:

```bash
/bin/zsh scripts/setup-macos.zsh
```

Скрипт пропускает уже установленные зависимости и ставит недостающие через Homebrew: Node.js, `cwebp` и `ffmpeg`. Также он пересобирает macOS launcher и маленький helper сохранения даты создания под текущую архитектуру Mac и делает smoke-test запуска. В готовом приложении helper уже встроен; устанавливать компилятор на другой Mac не требуется.

Старый launcher (требует исходники и установленные зависимости, не переносимая сборка):

```text
macos/Obsidian Screenshot Importer.app
```

Двойной клик запускает локальный сервис, открывает браузер и показывает маленькое окно с кнопками `Open App` и `Stop Service`. Когда закончил работу, нажми `Stop Service`.

Fallback-запуск через Terminal:

```bash
cd obsidian-screenshot-importer
npm start
```

После запуска открой:

```text
http://localhost:3787
```

Для запуска из исходников `npm start` и `npm test` сначала собирают helper через Apple Command Line Tools. При прямом запуске `node src/server.mjs` или `node --test tests/*.test.mjs` предварительно выполни `npm run build:native`.

Остановка Terminal-запуска:

```text
Ctrl+C в терминале, где запущен npm start
```

Подробное описание, архитектура, правила сопоставления и формат rollback лежат в [PROJECT.md](PROJECT.md).
